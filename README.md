# AS Nutritions

Premium sports nutrition ecommerce website.

## Technology Stack

- Angular 19
- TypeScript
- SCSS
- Bootstrap 5
- Bootstrap Icons

## Features

- Responsive homepage
- Product catalogue
- Product details
- Product search and filtering
- Shopping cart
- Quantity management
- Local storage cart persistence
- Responsive navigation

## Development Server

Run:

npm install

ng serve

Open http://localhost:4200/

## Production Build

ng build
